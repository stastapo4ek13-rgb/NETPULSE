## 🚀 Быстрый старт

1. Скачайте готовый **`NETPULSE.exe`** из раздела **Releases** справа.
2. Запустите файл — при первом старте NETPULSE сам предложит автоматически скачать актуальные ядра `xray.exe` и `sing-box.exe` (также это можно сделать в любой момент в меню **`14 -> 5`**).
3. Для работы режима **`TUN-Split`** и роутинга по программам запускайте от имени **Администратора**.

## 🔥 Ключевые возможности V2.0

### 🌐 Умный поиск, фильтрация и обход блокировок
* **Агрегация из 100+ источников:** автоматический сбор конфигураций из GitHub-репозиториев, Telegram-каналов и веб-подписок с поддержкой пользовательских списков (`custom_sources.txt`).
* **Все современные протоколы:** `VLESS` (Reality / XTLS / WS / gRPC), `Hysteria2`, `Trojan`, `TUIC`, `Shadowsocks`.
* **Защита от белых списков (CDN + RU-SNI):** встроенный детектор и фильтр узлов с российскими SNI для стабильной работы в условиях жёстких ограничений.
* **TLS Fragment (Анти-DPI):** встроенная фрагментация `tlshello`-пакетов в ядре `Xray` для обхода глубокой фильтрации провайдера (ТСПУ).
* **Многоэтапная проверка качества:**
  * Реальный TCP/TLS хендшейк и проверка GeoIP (с автоматическим исключением RU-узлов).
  * Замер реальной скорости скачивания (`Mbps`) и пинга (`ms`).
  * Глубокий тест узла: Jitter, доступность **YouTube 4K60**, **ChatGPT / AI** и проверка на утечку реального IP.

### 🛡️ Встроенный VPN-клиент, Split-Tunneling и Авто-лечение
* **Два режима работы:**
  * **Системный прокси** (`HTTP/SOCKS5`) с автонастройкой Windows.
  * **TUN-Split (Раздельное туннелирование):** весь зарубежный трафик идёт через VPN-туннель `sing-box`, а российские сайты (`*.ru`, `*.рф`, банки, Госуслуги, Яндекс, VK) и локальная сеть работают напрямую без задержек.
* **Роутинг по `.exe` (Process Split-Tunneling):** пускайте через VPN только выбранные приложения (например, `discord.exe`, `chrome.exe`) или исключайте онлайн-игры из туннеля.
* **Автозагрузка Windows и Автоконнект по стране:** запуск вместе с системой (в том числе сразу свёрнутым в трей) и автоматическое подключение к лучшему серверу выбранной страны (`DE`, `NL`, `FI` и др.).
* **Auto-Failover и Auto-Heal:** мгновенное переключение на резервный узел при обрыве связи и фоновая очистка Топ-10 от нерабочих серверов.
* **QR-коды для смартфона:** генерация чёткого QR-кода прямо в консоли для мгновенного переноса любого сервера в `v2rayNG`, `Hiddify` или `Streisand`.
* **Локальный сервер подписок:** раздача готовых подписок по сети (`/sub`, `/clash`, `/sb`).

### 🎨 Киберпанк HUD-интерфейс и кастомизация
* **Адаптивный широкий экран (`LIVE DASHBOARD`):** телеметрия в реальном времени, спидометр трафика (`DL / UL`), журнал событий и запуск Топ-5 серверов в 1 клик.
* **Непрозрачный HUD-оверлей поверх экрана:** контрастная мини-панель статуса в углу экрана, не мешающая кликам мыши.
* **Студия кастомизации (`13`):** 15 цветовых тем + свой `#HEX` / `RGB`, 3 режима RGB-градиента логотипа, 5 ASCII-баннеров, 6 стилей текста и 10 анимированных фонов.
* **Автоперевод раскладки `ЙЦУКЕН -> QWERTY`:** все горячие клавиши срабатывают без переключения языка клавиатуры.
* **Ярлык на Рабочий стол с иконкой** (`14 -> 2`) и сворачивание в системный трей Windows (`W`).

## ⌨️ Горячие клавиши главного меню

| Клавиша (EN / RU) | Действие |
| :--- | :--- |
| **`1`** | Запустить поиск новых серверов / допроверить кэш |
| **`2`** | Проверить серверы из буфера обмена (`Clipboard Scan`) |
| **`3`** | Открыть **Менеджер серверов** (Proxy/TUN, тесты 4K/AI, QR-код, избранное) |
| **`4`** | **Рейтинг репозиториев** и управление приоритетами (`★`) |
| **`P` / `З`** | **Пресеты охоты** (4 встроенных профиля + 3 личных слота `S5–S7`) |
| **`T1`–`T5` / `Е1`–`Е5`** | Мгновенное подключение к серверу из Топ-5 в `LIVE DASHBOARD` |
| **`D` / `В`** | Быстро отключить активный VPN-туннель |
| **`O` / `Щ`** | Включить / выключить плавающий **HUD-оверлей** поверх экрана |
| **`V` / `М`** | Переключить **Компактный** / **Полный** вид меню |
| **`W` / `Ц`** | Свернуть программу в **системный трей** |
| **`9`** | Настройки **GeoIP / Anti-DPI / TLS Fragment / Роутинг по `.exe`** |
| **`13`** | **Студия кастомизации** (цвета, градиент, фон, шрифты, темы) |
| **`14`** | Язык, ярлык с иконкой, ядра, токен, порт подписки, **Автозапуск Windows** |
