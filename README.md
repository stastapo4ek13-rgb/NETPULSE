# ⚡ NETPULSE v3.9 (сделано с помощью ии)

**Умный консольный VPN-агрегатор, парсер и клиент для Windows**  
*Smart Console VPN Aggregator, Scraper & Client for Windows*

> **Авторы / Authors:** Gemini & Glitch

---

## 🚀 Основные возможности / Key Features

* **Мульти-источники (GitHub + Telegram + Web):** автоматический поиск свежих репозиториев по 5 запросам, парсинг публичных Telegram-каналов (`t.me/s/`) и пользовательских списков (`custom_sources.txt`).
* **Поддержка современных протоколов:** `VLESS` (Reality / TLS / WS / gRPC), `Trojan`, `Shadowsocks`, а также `Hysteria2` (`hy2://`) и `TUIC` (`tuic://`).
* **Smart Pre-Filter + Batch Check:** отсев дубликатов и мусорных подсетей `/24` с последующей пакетной проверкой через `xray.exe` и `sing-box.exe` (ускорение валидации в 5–10 раз).
* **GeoIP и замер скорости:** определение выходной страны через Cloudflare Trace и реальный тест пропускной способности (Мбит/с).
* **Встроенный VPN-клиент (Proxy + TUN):**
  * **Proxy-режим:** автоматическая настройка системного прокси Windows.
  * **TUN-режим:** маршрутизация всего трафика ПК через виртуальный адаптер `NetPulseTUN` (требуются права Администратора).
* **Auto-Failover + Автоочистка:** фоновый контроль активного туннеля каждые 15 секунд с автоматическим переключением на следующий рабочий сервер и удалением упавших узлов.
* **Умные подписки (`/sub`, `/clash`, `/sb`):**
  * Локальный HTTP-сервер (`http://127.0.0.1:18080`) + автономные файлы `best_configs.txt`, `sub_clash.yaml`, `sub_singbox.json`.
  * Подписки для **Clash / Mihomo** и **Sing-box** включают группу автовыбора **`AUTO-BEST` (`url-test`)** и правила прямого обхода для РФ-сайтов (`.ru`, `.рф` → `DIRECT`).
  * Отдельные подписки по странам (`/de`, `/clash/nl`, `/sb/fi` и т.д.).
* **Менеджер серверов:** Избранное (`favorites.txt` с пометкой `★`), импорт/экспорт из буфера обмена или файла, 24-часовой карантин пустых баз (`netpulse_blacklist.json`) и автозагрузка ядер с GitHub.

## 🛠 Установка и запуск / Installation & Usage

### Вариант 1: Запуск из исходного кода (Python 3.10+)
1. Установите единственную внешнюю зависимость:
   ```bash
   pip install requests
   ```
2. Запустите скрипт:
   ```bash
   python netpulse.py
   ```
3. При первом запуске откройте **пункт 14 → 5** для автоматической загрузки ядер `xray.exe` и `sing-box.exe` с GitHub в папку `cores\`.

### Вариант 2: Готовый бинарник (`NETPULSE.exe`)
1. Скачайте `NETPULSE.exe` из раздела **Releases** (или соберите через PyInstaller).
2. Поместите файл в отдельную папку (например, `C:\NETPULSE\`) и запустите.
3. Для работы **TUN-режима** запускайте программу **от имени Администратора**.

## 🎮 Управление в Менеджере серверов (Пункт 2)

| Клавиша / Команда | Действие |
| :--- | :--- |
| **`1..N`** | Выбрать сервер (Подключить VPN / Тест пинга и скорости / Избранное `★` / Копировать / Удалить) |
| **`T`** | Переключить режим VPN: **System Proxy ↔ TUN (весь трафик ПК)** |
| **`F`** | Включить / выключить **Auto-Failover** (автопереключение при обрыве связи) |
| **`I`** | Импорт своих ссылок или Base64-подписки из буфера обмена / файла |
| **`E`** | Экспорт рабочего списка в Base64 (буфер обмена) или в `export_nodes.txt` |
| **`A`** | Перепроверить все серверы и автоматически удалить нерабочие (кроме Избранного) |
| **`D`** | Отключить активное VPN-соединение и сбросить системный прокси |

## 🔗 Локальные эндпоинты подписок (после сканирования)

* `http://127.0.0` — стандартная подписка Base64 (для v2rayN, v2rayNG, Nekoray)
* `http://127.0.0` — профиль для Clash Verge Rev, FlClash, Mihomo Party
* `http://127.0.0` — JSON-профиль для Sing-box, Karing, NekoBox, Hiddify
* `http://127.0.0<код_страны>` — фильтрация по стране (например: `/de`, `/clash/nl`, `/sb/fi`)
