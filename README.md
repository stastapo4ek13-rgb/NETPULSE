## ✨ Возможности / Features

* **Поиск в реальном времени (GitHub API):** Автоматический сбор свежих конфигураций `vless://` (Reality/TLS/WS/gRPC) и `trojan://` из публичных репозиториев с поддержкой персонального токена (до 5000 запросов/час).
* **Двухэтапная фильтрация без мусора:**
  * Мгновенный многопоточный TCP-отсев недоступных портов.
  * Реальная проверка прохождения HTTP-трафика в оперативной памяти (`stdin`) через ядро `xray.exe` без создания временных файлов на диске.
* **Точный GeoIP-фильтр по странам:** Определение страны по реальному IP-адресу сервера (а не по фейковым названиям в ссылках).
* **Замер реальной скорости скачивания:** Тестирование пропускной способности в Мбит/с (`Mbps`) и автоматическая сортировка от самых быстрых серверов к медленным.
* **Локальный сервер подписок:** Раздача готового списка в Base64 по локальному адресу `http://127.0.0` для **v2rayN** + сохранение в `best_configs.txt`.
* **Гибкое управление нагрузкой на ЦП:**
  * `Игровой режим` (12 потоков, пониженный приоритет процессов `xray.exe` — без фризов в играх).
  * `Средний режим` (35 потоков).
  * `Турбо режим` (80 потоков).
* **Анимированный TUI-интерфейс:** Выбор из 6 цветовых тем, 3 анимированных фонов (*Пульс*, *Матрица*, *Сетевой поток*), переключение языка (`RU / EN`), автосохранение настроек и генератор ярлыка на Рабочий стол.

## 🚀 Установка и запуск / Quick Start

### 1. Требования / Requirements
* Windows 10 / 11
* Python 3.8+
* Установленный клиент **v2rayN** (или отдельно скачанный `xray.exe`)

### 2. Установка зависимостей / Install dependencies
```bash
pip install requests
```

### 3. Настройка пути к Xray / Configure Xray path
Откройте скрипт и при необходимости укажите свой путь к `xray.exe` в строке `XRAY_PATH`:
```python
XRAY_PATH = r"C:\vpns\v2rayN-windows-64\bin\xray\xray.exe"
```

### 4. Запуск / Run
```bash
python netpulse.py
```
*(В главном меню выберите пункт `10`, чтобы добавить ваш GitHub Personal Access Token для снятия лимитов API, и пункт `9`, чтобы создать ярлык на Рабочем столе).*

## 🔒 Безопасность / Security
Файл настроек `netpulse_config.json` создается локально при первом изменении параметров. **Не загружайте `netpulse_config.json` в публичные репозитории**, если в нем сохранен ваш личный GitHub-токен.
