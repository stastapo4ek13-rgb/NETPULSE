## 🔥 Ключевые возможности

### 🚀 Умный поиск и фильтрация (Multi-Source Discovery)
* **Агрегация из 100+ источников:** автоматический парсинг актуальных конфигураций из GitHub-репозиториев, Telegram-каналов и веб-подписок с поддержкой пользовательских списков.
* **Поддержка всех современных протоколов:** `VLESS` (Reality / XTLS / WS / gRPC), `Hysteria2`, `Trojan`, `TUIC`, `Shadowsocks`.
* **Обход белых списков (White-List / RU-SNI):** встроенный детектор и фильтр узлов с российскими SNI/CDN для работы в условиях жёстких ограничений.
* **Многоэтапная проверка качества:**
  * Реальный TCP/TLS хендшейк и проверка GeoIP (с автоматическим исключением RU-серверов).
  * Замер реальной скорости скачивания (`Mbps`) и пинга (`ms`) через ядра `Xray` / `sing-box`.
  * Глубокий тест узла: Jitter, доступность **YouTube 4K60**, **ChatGPT / AI** и проверка на утечку реального IP.
* **Умный кэш и рейтинг баз:** недопроверенные узлы сохраняются в кэш для допроверки, а нерабочие источники автоматически понижаются в рейтинге.

### 🛡️ Встроенный VPN-клиент и Авто-лечение
* **Два режима работы на выбор:**
  * **Системный прокси** (`HTTP/SOCKS5`) с автонастройкой Windows.
  * **TUN-Split (Раздельное туннелирование):** весь зарубежный трафик идёт через VPN-туннель `sing-box`, а российские сайты (`*.ru`, `*.рф`, банки, Госуслуги, Яндекс, VK) и локальная сеть работают напрямую без задержек.
* **Auto-Failover (Авто-переключение):** если текущий сервер перестал отвечать, NETPULSE сам мгновенно переключает туннель на следующий рабочий узел из списка.
* **Auto-Heal (Фоновое авто-лечение):** раз в 20 минут тихо проверяет Топ-10 серверов в фоне, вычищая отвалившиеся узлы.
* **Локальный сервер подписок:** раздача готовых подписок по локальной сети (`/sub`, `/clash`, `/sb`) для `v2rayN`, `NekoBox`, `Hiddify` и других клиентов.

### 🎨 Киберпанк HUD-интерфейс и удобство
* **Адаптивный широкий экран (`LIVE DASHBOARD`):** при достаточной ширине окна справа отображается живая телеметрия, спидометр трафика (`↓ / ↑ Mbps`), журнал событий и Топ-5 серверов с запуском в 1 клик.
* **Плавный HUD-оверлей поверх окон:** полупрозрачная мини-панель в стиле NVIDIA Performance Overlay, не мешающая кликам мыши.
* **Полная кастомизация (`Customization Studio`):**
  * 15 цветовых тем + поддержка любого пользовательского `#HEX` и `RGB`.
  * 3 режима RGB-градиента логотипа (включая анимацию *«Живая волна»*).
  * 5 ASCII-баннеров, 6 стилей текста и 10 анимированных фонов во весь экран.
* **Работа с любой раскладкой клавиатуры:** встроенный транслятор `ЙЦУКЕН -> QWERTY` позволяет нажимать все горячие клавиши, не переключая язык на английский.
* **Сворачивание в системный трей Windows** с всплывающими уведомлениями и быстрым переключением серверов.

## ⌨️ Горячие клавиши главного меню

| Клавиша (EN / RU) | Действие |
| :--- | :--- |
| **`1`** | Запустить поиск новых серверов / допроверить кэш |
| **`2`** | Проверить серверы из буфера обмена (`Clipboard Scan`) |
| **`3`** | Открыть **Менеджер серверов** (Proxy/TUN, тесты 4K/AI, избранное) |
| **`4`** | **Рейтинг репозиториев** и управление приоритетами (`★`) |
| **`P` / `З`** | **Пресеты охоты** (4 встроенных профиля + 3 личных слота `S5–S7`) |
| **`T1`–`T5` / `Е1`–`Е5`** | Мгновенное подключение к серверу из Топ-5 в `LIVE DASHBOARD` |
| **`D` / `В`** | Быстро отключить активный VPN-туннель |
| **`O` / `Щ`** | Включить / выключить плавающий **HUD-оверлей** поверх экрана |
| **`V` / `М`** | Переключить **Компактный** / **Полный** вид меню |
| **`W` / `Ц`** | Свернуть программу в **системный трей** |
| **`13`** | **Студия кастомизации** (цвета, RGB-градиент, фон, шрифты, темы) |

## 📦 Установка и запуск

1. **Требования:**
   * Windows 10 / 11, линукс не поддерживается и не будет поддерживатся

2. **Клонирование и установка зависимостей:**
не нужно потому что exe все сам создает 

3. **Запуск:**
запустить exe файл в папке и в приложении добавить ярлык-батник
   > При первом запуске NETPULSE предложит автоматически скачать актуальные ядра `xray.exe` и `sing-box.exe` (также это можно сделать в любой момент через меню **`14 -> 5`**).
